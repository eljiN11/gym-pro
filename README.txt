==========================================
  GYMPRO - PREMIUM GYM LANDING PAGE
==========================================

Thank you for choosing GymPro! This is a fully responsive, modern, and high-converting landing page designed for gyms and fitness trainers.

=== FILES INCLUDED ===
- index.html (Main HTML structure)
- style.css  (Styling and responsive design)
- script.js  (Interactivity: mobile menu, scroll effects, etc.)

=== HOW TO USE ===
1. Download all three files (index.html, style.css, and script.js) and keep them in the same folder.
2. Open index.html in any modern web browser (Chrome, Safari, Firefox, Edge) to view the page.
3. To edit the text or images, open index.html in a text editor (e.g., VS Code, Sublime Text, Notepad).
4. To modify the theme colors, fonts, or layout styles, edit the style.css file.

=== IMAGES ===
All placeholder images are high-quality assets sourced from Unsplash. You can easily replace them with your own custom images by updating the image URLs directly in the HTML.

=== KEY FEATURES ===
- "Midnight Power" Dark Mode Theme with neon red/orange accents (#ff3b30)
- Fully Responsive Layout (Optimized for Mobile, Tablet, and Desktop)
- Sticky Navbar with smooth mobile menu toggle and ScrollSpy active states
- Engaging Hero Section with clear call-to-action buttons
- Features, Classes, Trainers, Pricing, and Testimonials sections
- Clean, modular, and production-ready code
